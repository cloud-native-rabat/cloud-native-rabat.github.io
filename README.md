# Cloud Native Rabat – Official CNCF Chapter

This repository hosts the GitHub Pages site for **Cloud Native Rabat**, the official CNCF (Cloud Native Computing Foundation) community chapter in Rabat, Morocco.

## About
Cloud Native Rabat brings together students, professionals, and technology enthusiasts to learn, share, and collaborate around Cloud Native technologies such as Kubernetes, Docker, Prometheus, and more.

## Goals
- Educate & inspire the local community about Cloud Native concepts and tools.
- Organize workshops, meetups, and hackathons for hands-on learning.
- Create networking opportunities between students, industry experts, and open-source contributors.
- Follow CNCF’s vendor neutrality guidelines in all activities.
- Empower careers by building globally in-demand skills.
